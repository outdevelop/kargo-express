# Карго Экспресс

Сайт ООО «Карго Экспресс» — перевозка автомобилей автовозами.

- `/` — лендинг с формой заявки
- `/cabinet/` — личный кабинет клиента: вход по звонку, статус перевозки, автовоз на карте
- `/admin/` — админ-панель: заявки, статусы, привязка автовоза (ГЛОНАСС)

## Запуск

Нужен Node.js 22.13 или новее.

```bash
npm install
cp .env.example .env   # задайте ADMIN_PASSWORD
npm start
```

Сайт откроется на http://localhost:4173. База (SQLite) создаётся сама в папке `data/`.

## Настройки (.env)

| Переменная | Что делает |
| --- | --- |
| `ADMIN_PASSWORD` | Пароль для входа в админ-панель |
| `TRUST_PROXY` | `1`, если сайт стоит за nginx с https |
| `FLASHCALL_MODE` | `mock` — код входа показывается на экране; боевой режим — в `server/flashcall.js` |
| `GLONASS_MODE` | `mock` — демо-автовозы; боевой режим — в `server/glonass.js` |

## Что ещё не подключено

- **flashcall.ru** — `server/flashcall.js`, функция `sendCode`.
- **ГЛОНАСС** — `server/glonass.js`, функции `listTrackers` и `getPosition`.

Пока оба модуля работают в демо-режиме; остальной код от режима не зависит.
